Install

Two lines, anywhere on the page

Drop the container where you want the widget to appear, and the script anywhere on the page. That is the whole installation.

<!-- where the widget should appear --> <div data-prfb-wire></div> <!-- anywhere on the page --> <script src="https://pressreleaseforbusiness.com/embed.js" defer></script>
What it renders Headline, date, issuing organization and a short snippet — each linking to the full release here. It does not and cannot render full release text.

Running a publication or a trade site? Every release here is available as a feed, as JSON and as a widget, with no account and no permission needed. Feeds, API and republishing terms →

Options

Configure it with attributes

Every option is set on the container div
AttributeValuesDefault
data-feedall, optimized, featured, or a category slugall
data-count1–205
data-themeauto, light, darkauto
data-layoutlist, compact, cardslist
data-titleAny text, or empty for no heading Latest announcements
data-snippettrue, false true

Category feeds

Show only announcements relevant to your audience:

<div data-prfb-wire data-feed="home-services" data-count="4"></div>

Available: accessibility, ecommerce, education, health, home-services, insurance, marketing, retail, small-business, technology

A sidebar on a dark site

<div data-prfb-wire data-feed="technology" data-count="6" data-layout="compact" data-theme="dark" data-title="Industry announcements"></div>
For developers

Or use the JSON directly

If you would rather render it yourself, every feed is available as JSON with permissive cross-origin access.

// all releases https://pressreleaseforbusiness.com/api/releases.json // optimized and network tier only https://pressreleaseforbusiness.com/api/optimized.json // by category https://pressreleaseforbusiness.com/api/home-services.json

Each release carries headline, snippet, url, organization, date, categories, tier and optimized. RSS is at /feed.xml with a WebSub hub declared, so subscribers are notified the moment something publishes.

Republishing terms Headline, snippet and link may be republished freely with attribution and a link to the canonical release. Full release text may not be republished. This is not a licensing technicality — duplicating full announcements across many sites is the pattern search engines act against, and it would damage both of us.
